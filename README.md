## FAQ

VideoPatch modifies application memory and files. Use it at your own risk and ensure you have backups of your projects.

### Which operating systems are supported?

VideoPatch is designed exclusively for Windows 10 and Windows 11 desktop operating systems.

### Will this affect my existing projects?

No, VideoPatch only modifies the editor application itself. Your saved project files remain untouched.

### How often should I run VideoPatch?

Only run it once after installing or updating your video editor software. Running it repeatedly is unnecessary.

### Do I need to disable my anticomponent software?

Some security tools may flag patching utilities. You may need to add an exception or temporarily disable real-time protection during use.

### Does this work with the latest version of the editors?

VideoPatch is updated periodically. Check the compatibility notes in the release for supported version ranges.

### Can I use this on multiple computers?

Yes, you can transfer and use VideoPatch on any compatible Windows system where the supported editors are installed.

### What if the patch doesn't work for my editor?

Ensure you're using a supported version and that you've closed the editor completely before patching. Check the FAQ for troubleshooting steps.
